Project 01 — Network Tooling

Network Packet Scanner

An automated ARP-based network scanner built in Python with the Scapy packet-manipulation library inside VS Code. The script broadcasts ARP requests across a local subnet, listens for replies, and logs every responding host with its IP and MAC address — a fast, dependency-light way to map a live network without touching a full port scan.

Python 3ScapyARP Protocol MAC DetectionVS Code

Project 02 — Security Research

Web Application Vulnerability Testing

Systematic vulnerability assessment on PortSwigger Web Security Academy labs, focused on discovering, exploiting and mitigating SQL injection attack vectors. Each lab involves intercepting requests through Burp Suite, isolating the injectable parameter, proving impact with a controlled payload, then reasoning through the defensive fix — parameterized queries, input validation and least-privilege database accounts.
